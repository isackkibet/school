# ICS IXL System Dependency Map

IXL is not a duplicate of ICS Live, Smart Prospectus, Smart Lecturer, AI E-Library, YohPal Brain, YohPal Jobs, or YohPal Hustle.

## Ownership
- IXL: Identity, SSO, profile shell, roles, navigation, transcript passport, graduate handoff.
- Smart Prospectus: Course catalogue, course fees, entry requirements, practical requirements.
- ICS Live: Detailed academic operations, Student CRM, finance, payments, HR, exams, academic governance.
- Smart Lecturer: AI classroom delivery and AI learning operations.
- AI E-Library: Reference materials, notes, books, past papers, practical manuals.
- YohPal Brain: Sole AI/LLM gateway, connected to OpenAI.
- YohPal Jobs/Hustle: Employment and self-employment pathways.

## Student Routing
- Physical / Live Virtual -> ICS Live.
- AI Virtual -> Smart Lecturer.
- All modes use IXL identity, AI E-Library resources, and ICS Live as final academic record owner.
